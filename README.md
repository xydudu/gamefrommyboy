# ⚔️ 征服者 - 策略战争游戏

一个基于 HTML5 + JavaScript 的轻量级策略战争游戏。

**在线试玩：** http://49.51.247.20:8080/

---

## 🎮 游戏特色

### 核心玩法
- **地图征服**：8个不同难度的领地等待征服
- **兵种招募**：6种特色兵种，各具特点
- **升级系统**：兵种可无限升级，每次+20%属性
- **解锁机制**：逐步解锁更强力的兵种

### 战斗系统
- **实时动画**：战斗过程可视化，双方血条动态变化
- **回合制攻防**：我方攻击 → 敌方反击 → 循环
- **暴击机制**：随机暴击，伤害×1.5倍
- **跳过功能**：可跳过战斗直接看结果

### 兵种介绍

| 兵种 | 图标 | 解锁价格 | 招募价格 | 特点 |
|------|------|----------|----------|------|
| 步兵 | ⚔️ | 初始解锁 | 50 | 攻守平衡 |
| 弓箭手 | 🏹 | 200 | 80 | 高攻低防 |
| 长矛兵 | 🔱 | 300 | 100 | 高血量 |
| 盾兵 | 🛡️ | 400 | 120 | 极高防御 |
| 骑兵 | 🐴 | 500 | 150 | 高速突击 |
| 坦克 | ⚙️ | 600 | 200 | 终极单位 |

## 🏗️ 技术架构

- **前端**：纯 HTML5 + CSS3 + JavaScript
- **无依赖**：零第三方库，单文件运行
- **响应式**：适配桌面和移动设备

---

## 🚀 本地运行

```bash
# 克隆仓库
git clone https://github.com/xydudu/gamefrommyboy.git

# 进入目录
cd gamefrommyboy

# 启动本地服务器（任选其一）
python3 -m http.server 8080
# 或
npx serve .

# 浏览器访问 http://localhost:8080
```
