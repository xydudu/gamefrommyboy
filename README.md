# ⚔️ 征服者 - 策略战争游戏

一个基于 HTML5 + JavaScript 的轻量级策略战争游戏，具有完整的难度系统、兵种克制和随机事件机制。

**在线体验**: http://49.51.247.20:8080/index.html

---

## 🎮 游戏特色

### 核心玩法
- **地图征服**：8 个不同难度的领地等待征服
- **兵种招募**：6 种特色兵种，各具特点
- **升级系统**：兵种可无限升级，每次 +20% 属性
- **难度成长**：胜利次数越多，敌人越强

### 战斗系统
- **实时动画**：战斗过程可视化，双方血条动态变化
- **回合制攻防**：我方攻击 → 敌方反击 → 循环
- **暴击机制**：随机暴击，伤害×1.5 倍
- **跳过功能**：可跳过战斗直接看结果

### 难度系统 ⭐

#### 1. 动态难度成长
每场胜利后敌人属性提升，难度呈指数增长：
```
难度倍率 = 1 + (胜利次数 × 0.12) + (胜利次数² × 0.005)
```

| 胜利次数 | 难度倍率 | 敌人强度 |
|---------|---------|---------|
| 0 场 | 100% | 基础 |
| 5 场 | 172% | +72% |
| 10 场 | 270% | +170% |
| 20 场 | 540% | +440% |

#### 2. 兵种克制系统
```
        ⚔️ 步兵
       /      \
   克制      被克
     ↓          ↓
  🐴骑兵 ←→ 🏹弓箭手
```

| 克制关系 | 攻击加成 | 防御加成 | 暴击加成 |
|---------|---------|---------|---------|
| 克制对方 | +40% | +20% | +10% |
| 被克制 | -25% | -30% | -5% |
| 长矛兵 vs 骑兵 | +60% | +30% | +15% |

#### 3. 连战疲劳系统
- 连续战斗每场 -8% 属性惩罚
- 返回地图重置疲劳
- 鼓励战略性撤退

#### 4. 兵力损耗系统
- 战斗后损失 5-50% 兵力
- 胜利减少损耗，失败增加损耗
- 连战疲劳增加损耗

#### 5. 随机事件系统
18 种随机事件，每 2 回合触发：

| 类型 | 事件示例 | 效果 |
|------|---------|------|
| 天气 | 沙尘暴、暴雨、大雾 | 影响命中、速度 |
| 变异 | 狂暴化、铁壁觉醒 | 攻防临时变化 |
| 地形 | 地面塌陷、高地优势 | 改变战场环境 |
| 士气 | 军心涣散、背水一战 | 影响全军属性 |
| 传奇 | 流星坠落、神兽降临 | 低概率高影响 |

### 胜利后选择
战斗胜利后可选择：
- **⚔️ 继续当前征战**：返回地图，保持当前难度
- **🔥 挑战下一难度**：难度 +24%，清空兵种，直接进入下一场战斗

## 🏗️ 技术架构

- **前端**：纯 HTML5 + CSS3 + JavaScript
- **无依赖**：零第三方库，单文件运行
- **响应式**：适配桌面和移动设备
- **代码量**：~1500 行 HTML + CSS + JS

### 文件结构

```
gamefrommyboy/
├── game_public/
│   ├── index.html          # 主游戏文件（所有逻辑）
│   └── icons_new/          # 游戏图标资源
├── README.md               # 项目文档
└── .gitignore             # Git 忽略配置
```

### 核心系统模块

```javascript
// 1. 游戏数据管理
const gameData = {
  gold, victoryCount, difficultyScale,
  recruitedUnits, activeEvents, ...
}

// 2. 难度系统
- calculateDifficultyScale()    // 计算难度倍率
- getCounterModifier()          // 兵种克制计算
- applyUnitCounters()           // 应用克制效果
- getFatiguePenalty()           // 连战疲劳计算
- calculateCasualties()         // 兵力损耗计算

// 3. 战斗系统
- showBattleProcess()           // 显示战斗动画
- processBattleRound()          // 处理战斗回合
- finishBattleProcess()         // 结束战斗

// 4. 随机事件系统
- checkRandomEvents()           // 检查事件触发
- activateEvent()               // 激活事件
- applyEventEffects()           // 应用事件效果

// 5. UI 系统
- renderMap()                   // 渲染地图
- renderUnits()                 // 渲染兵种
- updateDifficultyDisplay()     // 更新难度显示
```

## 🚀 本地运行

```bash
# 克隆仓库
git clone https://github.com/xydudu/gamefrommyboy.git

# 进入目录
cd gamefrommyboy

# 启动本地服务器（任选其一）
python3 -m http.server 8080
# 或
npx serve .

# 浏览器访问 http://localhost:8080
```
