## 一、兵种数值重新平衡

### 优化前 vs 优化后对比

| 兵种 | 原攻击 | 新攻击 | 原 HP | 新 HP | 成本 | 变化说明 |
|------|--------|--------|-------|-------|------|----------|
| 步兵 | 20 | 20 | 100 | 100 | 50 | 基准不变 |
| 弓箭手 | 35 | 30 | 60 | 80 | 80 | 攻击 -5, HP +20，提高生存 |
| 长矛兵 | 25 | 22 | 120 | 140 | 100 | 攻击 -3, HP +20，强化反骑定位 |
| 盾兵 | 15 | 18 | 150 | 180 | 120 | 攻击 +3, HP +30，明确坦克定位 |

| 坦克 | 60 | 55 | 200 | 220 | 200 | 攻击 -5, HP +20，终极单位定位 |

### 设计原理

**成本效率公式**:
```
效率 = (Attack × 0.6 + HP × 0.4) / Cost
目标：所有兵种效率在 0.35-0.45 区间
```

优化后效率：
- 步兵：0.40（基准）
- 弓箭手：0.375
- 长矛兵：0.22
- 盾兵：0.15
- 骑兵：0.28
- 坦克：0.275

## 二、升级曲线优化

### 原公式（线性增长，过快）
```javascript
multiplier = 1 + (level - 1) * 0.2
```

### 新公式（多项式温和增长）
```javascript
const level = levelData.level;
const multiplier = 1 + (level - 1) * 0.15 + Math.pow(level - 1, 2) * 0.005;
```

### 倍率对照表

| 等级 | 原倍率 | 新倍率 | 变化 |
|------|--------|--------|------|
| 1 | 1.00 | 1.00 | = |
| 5 | 1.80 | 1.68 | -7% |
| 10 | 2.80 | 2.80 | = |
| 15 | 3.80 | 4.30 | +13% |
| 20 | 4.80 | 6.15 | +28% |
| 30 | 6.80 | 10.90 | +60% |

**设计意图**: 前 10 级保持相近体验，后期拉开差距，增加长期追求。

## 三、难度曲线软上限设计

### 原公式（指数爆炸）
```javascript
scale = 1 + (victoryCount * 0.12) + (victoryCount² * 0.005)
```

### 新公式（软上限）
```javascript
function calculateDifficultyScale() {
    const softCap = 30;  // 30 场后增长放缓

    if (gameData.victoryCount <= softCap) {
        // 前 30 场：正常增长
        return 1 + (gameData.victoryCount * 0.15) + Math.pow(gameData.victoryCount, 2) * 0.003;
    } else {
        // 超过 30 场：增长放缓（每场只 +5%）
        const baseAtCap = 1 + (softCap * 0.15) + Math.pow(softCap, 2) * 0.003;
        const beyond = gameData.victoryCount - softCap;
        return baseAtCap + (beyond * 0.05);
    }
}
```

### 难度对照表

| 胜利次数 | 原倍率 | 新倍率 | 变化 |
|----------|--------|--------|------|
| 0 | 100% | 100% | = |
| 10 | 170% | 190% | +12% |
| 20 | 340% | 310% | -9% |
| 30 | 640% | 460% | -28% |
| 50 | 850% | 560% | -34% |
| 100 | 2200% | 810% | -63% |

**设计意图**: 防止后期数值爆炸，保持游戏可玩性。

## 四、兵种克制系统深化

### 克制倍率配置

```javascript
const COUNTER_MODIFIERS = {
    // 基础克制（克制方）
    strong: { attackMultiplier: 1.3, defenseMultiplier: 1.15, critBonus: 0.1 },
    // 被克制方
    weak: { attackMultiplier: 0.8, defenseMultiplier: 0.75, critBonus: -0.05 },
    // 特效克制（长矛 vs 骑兵）
    bonus: { attackMultiplier: 1.5, defenseMultiplier: 1.25, critBonus: 0.15 },
    // 特效防御（盾兵 vs 远程）
    resist: { rangedDamageReduction: 0.4, attackMultiplier: 1.1 },
    // 默认（无克制）
    neutral: { attackMultiplier: 1.0, defenseMultiplier: 1.0, critBonus: 0 }
};
```

### 克制关系矩阵

```javascript
unitCounters: {
    infantry: { strong: ['cavalry'], weak: ['archer'] },
    archer: { strong: ['infantry'], weak: ['cavalry'] },
    cavalry: { strong: ['archer'], weak: ['infantry'] },
    pikeman: { strong: ['infantry'], weak: ['archer'], bonusVs: ['cavalry'] },
    shieldman: { strong: ['infantry'], weak: ['cavalry'], resistVs: ['archer'] },
    tank: { strong: [], weak: [], immune: true }
};
```

### 新增函数

**getBestCounterModifier**: 计算军团最佳克制关系
```javascript
function getBestCounterModifier(attackerUnits, defenderUnits) {
    let bestMultiplier = 1.0;
    let bestCritBonus = 0;

    attackerUnits.forEach(attacker => {
        defenderUnits.forEach(defender => {
            const mod = getCounterModifier(attacker.id, defender.id);
            if (mod.attackMultiplier > bestMultiplier) {
                bestMultiplier = mod.attackMultiplier;
                bestCritBonus = mod.critBonus;
            }
        });
    });

    return {
        playerMultiplier: bestMultiplier,
        playerCritBonus: bestCritBonus,
        hasCounter: bestMultiplier > 1.0,
        isCountered: bestMultiplier < 1.0
    };
}
```

## 五、战斗伤害计算优化

### 原计算（简单减法）
```javascript
enemyHp -= totalAttack;
```

### 新计算（应用克制和暴击）
```javascript
// 计算克制倍率
const bestCounterMod = getBestCounterModifier(playerUnits, enemyUnits);
let playerDamage = playerStats.attack;

// 应用克制倍率
if (bestCounterMod.playerMultiplier > 1) {
    playerDamage = Math.floor(playerDamage * bestCounterMod.playerMultiplier);
}

// 暴击判定（基础 20% + 克制 bonus）
const playerCritChance = 0.2 + Math.max(0, bestCounterMod.playerCritBonus || 0);
const isPlayerCrit = Math.random() < playerCritChance;
const actualPlayerDamage = isPlayerCrit ? Math.floor(playerDamage * 1.5) : playerDamage;
```

```javascript
// 1. 验证兵种性价比
gameData.units.forEach(unit => {
    const efficiency = (unit.baseAttack * 0.6 + unit.baseHp * 0.4) / unit.baseCost;
    console.log(`${unit.name}: 效率 = ${efficiency.toFixed(3)}`);

// 2. 验证升级曲线
for (let i = 1; i <= 20; i++) {
    const level = i;
    const mult = 1 + (level - 1) * 0.15 + Math.pow(level - 1, 2) * 0.005;
    console.log(`Lv.${i}: ${mult.toFixed(2)}x`);
}

// 3. 验证难度曲线
for (let i = 0; i <= 100; i += 10) {
    let scale;
    const softCap = 30;
    if (i <= softCap) {
        scale = 1 + (i * 0.15) + Math.pow(i, 2) * 0.003;
    } else {
        const baseAtCap = 1 + (softCap * 0.15) + Math.pow(softCap, 2) * 0.003;
        scale = baseAtCap + ((i - softCap) * 0.05);
    }
    console.log(`${i}胜：${(scale * 100).toFixed(0)}%`);
}
```
