# 征服者 - 微信小程序版本

策略战争游戏的微信小程序实现。

## 项目结构

```

├── app.js                 # 小程序入口
├── app.json              # 全局配置
├── app.wxss              # 全局样式
├── project.config.json   # 项目配置
├── sitemap.json          #  sitemap 配置
├── pages/
│   ├── index/           # 主界面（地图/征兵/升级）
│   ├── battle/          # 战斗界面
│   └── result/          # 战斗结果
├── components/
│   ├── toast/           # Toast 提示组件
│   └── unit-card/       # 兵种卡片组件
└── utils/
    └── game-utils.js    # 游戏工具函数
```

## 功能说明

### 1. 征兵系统
- 点击未解锁兵种 → 消耗金币解锁
- 点击已解锁兵种 → 消耗金币招募
- 解锁费用：200-600 金币（根据兵种）
- 招募费用：50-200 金币（根据兵种）

### 2. 升级系统
- 点击右上角"📈升级"按钮打开升级面板
- 消耗金币提升兵种等级
- 每级提升 15% 属性（攻击和 HP）
- 升级费用随等级增长

### 3. 侦察系统
- 点击领地左上角"🔍"按钮侦察
- 消耗 100 金币查看敌方兵力配置
- 侦察信息永久保存
- 战斗时显示侦察提示

### 4. 军团管理
- 点击顶部"🎖️军团"按钮展开面板
- 查看每个单位 HP 状态
- 单个治疗：20 金币/单位
- 单个解散：移除单位
- 全体治疗：20 金币×受伤单位数

### 5. 战斗系统
- 自动回合制战斗
- 应用兵种克制倍率
- 10% 基础暴击率 + 克制加成
- 战斗动画和详细日志
- 难度影响敌方属性和奖励

### 6. 游戏结局

**Game Over 条件：**
- 连败 3 场 → "连战连败，军心溃散"
- 通关条件：征服 8 个领地

**结局类型：**
- 普通结局：显示本场战斗结果
- Game Over 结局：显示统计数据，可重新开始
- 通关结局：恭喜通关，显示完整统计

## 开发指南

### 1. 安装微信开发者工具
下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 2. 导入项目
- 打开微信开发者工具
- 选择"导入项目"
- 选择 `miniprogram` 目录
- 填入 AppID（测试可选"测试号"）

### 3. 开发调试
- 实时预览修改
- 使用控制台调试
- 使用真机调试预览效果

### 4. 配置说明

**app.json**
- `pages`: 页面路径列表
- `window`: 窗口表现配置
- `style`: 使用新版基础库

**project.config.json**
- `appid`: 替换为你的小程序 AppID
- `compileType`: 小程序类型

## 数值配置

### 兵种数值
| 兵种 | 攻击 | HP | 解锁 | 招募 | 定位 |
|------|------|----|----|----|------|
| 步兵 | 20 | 100 | 0 | 50 | 基础 |
| 弓箭手 | 30 | 80 | 200 | 80 | 远程 |
| 长矛兵 | 22 | 140 | 300 | 100 | 反骑 |
| 盾兵 | 18 | 180 | 400 | 120 | 坦克 |
| 骑兵 | 42 | 100 | 500 | 150 | 突击 |
| 坦克 | 55 | 220 | 600 | 200 | 终极 |

### 克制关系
- 步兵 → 克制骑兵，被弓箭手克制
- 弓箭手 → 克制步兵，被骑兵克制
- 骑兵 → 克制弓箭手，被步兵克制
- 长矛兵 → 特效克制骑兵（1.5x）
- 盾兵 → 远程抗性（-40% 远程伤害）
- 坦克 → 免疫所有克制

### 升级曲线
- 1-5 级：每级 +15% 属性，费用×1.3
- 6 级后：每级 +15% 属性，费用×1.5

### Game Over 条件
1. 连续失败 3 场 → 连战连败
2. 征服所有 8 个领地 → 通关
