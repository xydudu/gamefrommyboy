# 征服者 - 微信小程序版本

策略战争游戏的微信小程序实现。

## 项目结构

```
miniprogram/
├── app.js                 # 小程序入口
├── app.json              # 全局配置
├── app.wxss              # 全局样式
├── project.config.json   # 项目配置
├── sitemap.json          #  sitemap 配置
├── pages/
│   ├── index/           # 主界面（地图/征兵）
│   ├── battle/          # 战斗界面
│   └── result/          # 战斗结果
├── components/
│   ├── toast/           # Toast 提示组件
│   └── unit-card/       # 兵种卡片组件
└── utils/
    └── game-utils.js    # 游戏工具函数
```

## 开发指南

### 1. 安装微信开发者工具
下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 2. 导入项目
- 打开微信开发者工具
- 选择"导入项目"
- 选择 `miniprogram` 目录
- 填入 AppID（测试可选"测试号"）

### 3. 开发调试
- 实时预览修改
- 使用控制台调试
- 使用真机调试预览效果

### 4. 配置说明

**app.json**
- `pages`: 页面路径列表
- `window`: 窗口表现配置
- `style`: 使用新版基础库

**project.config.json**
- `appid`: 替换为你的小程序 AppID
- `compileType`: 小程序类型

## 数值配置

### 兵种数值
| 兵种 | 攻击 | HP | 成本 | 定位 |
|------|------|----|----|------|
| 步兵 | 20 | 100 | 50 | 基础 |
| 弓箭手 | 30 | 80 | 80 | 远程 |
| 长矛兵 | 22 | 140 | 100 | 反骑 |
| 盾兵 | 18 | 180 | 120 | 坦克 |
| 骑兵 | 42 | 100 | 150 | 突击 |
| 坦克 | 55 | 220 | 200 | 终极 |

### 克制关系
- 步兵 → 克制骑兵，被弓箭手克制
- 弓箭手 → 克制步兵，被骑兵克制
- 骑兵 → 克制弓箭手，被步兵克制
- 长矛兵 → 特效克制骑兵（1.5x）
- 盾兵 → 远程抗性（-40% 远程伤害）
- 坦克 → 免疫所有克制

### Game Over 条件
1. 连续失败 3 场 → 连战连败
2. 金币<30 且无领地可征 → 穷途末路
