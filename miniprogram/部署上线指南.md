# 微信小程序部署上线指南

## 快速开始

### 1. 注册小程序账号

**地址**: https://mp.weixin.qq.com/

**流程**:
1. 点击"立即注册"
2. 选择"小程序"
3. 填写邮箱、密码
4. 邮箱激活
5. 信息登记（个人/企业）
6. 等待审核（1-7 工作日）

**费用**:
- 个人主体：免费
- 企业主体：300 元/年

---

### 2. 获取 AppID

审核通过后：
1. 登录小程序后台
2. 进入"开发" → "开发管理" → "开发设置"
3. 复制 **AppID (wx 开头)**

---

### 3. 配置项目

**修改 `project.config.json`**:
```json
{
  "appid": "你的 AppID"  // 替换这里的值
}
```

**修改 `app.json`** (如果需要):
```json
{
  "window": {
    "navigationBarTitleText": "征服者"  // 小程序名称
  }
}
```

---

### 4. 下载微信开发者工具

**下载地址**: https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

**安装后**:
1. 打开微信开发者工具
2. 使用微信扫码登录
3. 选择"导入项目"
4. 选择 `miniprogram` 目录
5. 填入你的 AppID

---

### 5. 开发调试

**功能**:
- 实时预览：修改代码自动刷新
- 真机预览：手机扫码测试
- 调试控制台：查看日志、网络请求
- 性能分析：检查性能问题

**测试重点**:
- [ ] 所有页面正常显示
- [ ] 所有功能正常工作
- [ ] 数据存储正常
- [ ] 无控制台错误

---

### 6. 上传代码

**在开发者工具中**:
1. 点击右上角"上传"按钮
2. 填写版本号和项目备注
   - 版本号：如 `1.0.0`
   - 备注：如 "初始版本，包含基本游戏功能"
3. 点击"上传"

**上传成功后**:
- 代码会出现在"版本管理"的"开发版本"中

---

### 7. 提交审核

**在小程序后台**: https://mp.weixin.qq.com/

1. 进入"版本管理"
2. 找到刚上传的开发版本
3. 点击"提交审核"

**需要填写**:
- **功能页面**: 列出所有功能页面路径
- **测试账号**: 如需要登录，提供测试账号
- **补充说明**: 游戏类目说明

**游戏类目选择**:
- 个人主体：选择"工具 - 效率"或"娱乐"
- 企业主体：可选择"游戏"类目（需要版号）

---

### 8. 审核注意事项

**游戏类小程序特殊要求**:

**个人主体**:
- ❌ 不能选择"游戏"类目
- ✅ 可选择"工具 - 效率"或"娱乐"
- ✅ 策略战争游戏通常可以过审
- ⚠️ 避免直接使用"游戏"字眼

**企业主体**:
- ✅ 可以选择"游戏"类目
- ⚠️ 需要游戏版号（ISBN）
- ⚠️ 无版号只能选择其他类目

**建议**:
- 首次上线选择"工具"或"娱乐"类目
- 名称避免"游戏"字样，可用"征服者 - 策略战争"

---

### 9. 审核通过并发布

**审核时间**: 通常 1-7 个工作日

**审核通过后**:
1. 收到审核通过通知
2. 进入"版本管理"
3. 点击"发布"
4. 确认发布

**发布后**:
- 用户可搜索小程序使用
- 可在小程序后台查看数据

---

## 常见问题

### Q1: 个人主体能做游戏小程序吗？

**答**: 个人主体不能选择"游戏"类目，但可以做策略类游戏，选择"工具"或"娱乐"类目。

### Q2: 需要游戏版号吗？

**答**: 
- 个人主体：不需要（因为不能选游戏类目）
- 企业主体：选择"游戏"类目需要版号

### Q3: 小程序名称有什么要求？

**答**:
- 不能与已有小程序重名
- 不能使用宽泛词（如"游戏"、"工具"）
- 不能包含敏感词
- 建议：使用独特名称 + 功能描述

### Q4: 审核被拒怎么办？

**答**:
1. 查看拒绝原因
2. 按要求修改
3. 重新提交审核
4. 如有异议可申诉

**常见拒绝原因**:
- 功能与类目不符
- 存在未公开的功能
- 用户体验问题
- 违规内容

### Q5: 如何添加服务器域名？

**答**:
1. 进入"开发" → "开发管理" → "开发设置"
2. 找到"服务器域名"
3. 添加你的域名（需要 HTTPS）
4. 保存配置

**注意**: 本地开发时可关闭域名校验

## 上线后运营

### 数据分析

**查看路径**: 小程序后台 → "统计"

**关键指标**:
- 访问人数（UV）
- 访问次数（PV）
- 停留时长
- 分享次数
- 新增用户

### 版本更新

1. 修改代码
2. 上传新版本
3. 提交审核
4. 发布新版本

### 用户反馈

- 小程序后台 → "客服" → "消息管理"
- 及时回复用户反馈
